# Decision Trees: Classification and Regression

## Overview

This project focuses on understanding and implementing decision trees for classification and regression tasks. The assignment is divided into three main sections, each designed to enhance your skills in using decision trees effectively.

## Key Topics

1. **Using Decision Trees for Classification**: Learn to apply decision trees from the `sklearn` library to classification problems. You will explore how decision boundaries are formed for different datasets and analyze the impact of various hyperparameters.
   
2. **Implementing a Custom Decision Tree**: Develop your own decision tree for classification and compare its performance with the standard implementation from `sklearn`.

3. **Regression Trees with Linear Models in Leaves**: Create a regression tree where linear models are used in the leaves, providing an advanced approach to handling regression tasks.

## Detailed Sections

### Part 1: Decision Trees and Visualization

- **Dataset Exploration**: Utilize `make_moons`, `make_circles`, and `make_classification` to create datasets and visualize decision boundaries based on various hyperparameters.
- **Overfitting Analysis**: Train decision trees with default parameters and evaluate them on training and test datasets to assess overfitting.

### Part 2: Hyperparameter Tuning

- **Regularization Parameters**: Experiment with parameters such as `max_depth` and `min_samples_leaf`. Visualize decision boundaries and evaluate model performance across different combinations.

### Bonus: Interactive Visualization

- **Plotly Integration**: Create an interactive visualization using `plotly.graph_objects` to dynamically adjust `max_depth` and `min_samples_leaf`, observing changes in decision boundaries and model predictions.
