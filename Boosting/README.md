# Machine Learning: Boosting Algorithm Implementation

## Overview

This project involves manually implementing a powerful machine learning algorithm—boosting. The assignment is designed to deepen your understanding of boosting techniques and their application in real-world scenarios.

## Key Topics

1. **Gradient Boosting Implementation**: Develop your own gradient boosting algorithm from scratch, focusing on the core principles and mechanics without relying on existing libraries.

2. **Hyperparameter Tuning and Regularization**: Implement various hyperparameters and regularization techniques to enhance model performance and prevent overfitting.

## Detailed Sections

### Task 1: Basic Gradient Boosting

- **Objective**: Implement a basic gradient boosting algorithm without using existing solutions unless specified.
- **Instructions**:
  - Complete the code in `boosting.py`, using the provided `Boosting` class template.
  - Implement key functions such as `__init__`, `fit`, `partial_fit`, `predict_proba`, and `plot_history`.
  - Ensure the model updates predictions and calculates errors correctly during training.

### Task 2: Hyperparameter Implementation

- **Objective**: Implement various hyperparameters and regularization techniques to improve model performance.
- **Instructions**:
  - Experiment with parameters to see their impact on model quality.
  - Focus on training and validation graphs to observe changes in performance.
  - Implement stopping criteria to prevent overfitting during training.
